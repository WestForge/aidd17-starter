# Delivery Rules

Rules for controlled AI-assisted delivery.

## Scope Control

- Capability docs may evolve.
- Delivery slices are frozen snapshots.
- Agents should implement the slice, not the current imagined future state.

## File Boundaries

- Touch only files listed in the delivery slice unless blocked.
- Report missing or conflicting files.

## Review

- Review against the delivery slice acceptance criteria.
- Report unauthorised file changes and scope creep.
