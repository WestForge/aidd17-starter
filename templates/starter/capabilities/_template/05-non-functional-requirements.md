# __CAPABILITY_TITLE__ Non-Functional Requirements


## Purpose

Define the quality attributes the capability must satisfy.

## Performance

- Response time, throughput, loading, or runtime expectations.

## Security

- Access, permissions, privacy, or trust boundaries.

## Reliability

- Failure handling, retry, durability, and fallback expectations.

## Maintainability

- Modularity, testability, naming, and ownership expectations.
