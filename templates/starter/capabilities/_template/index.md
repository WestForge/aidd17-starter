# Capability Template

This is the generic section template used to create real capabilities.

Do not implement work from this folder. Create a real capability first:

```powershell
npm run aidd:capability:create -- <capability-slug> --title "<Capability Title>"
```

Complete the files in numbered order. Once the capability definition is clear enough, create a delivery slice from the capability.
