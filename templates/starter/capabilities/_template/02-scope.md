# __CAPABILITY_TITLE__ Scope


## Purpose

Define the boundary of the capability.

## In Scope

- What belongs inside this capability?

## Out of Scope

- What should not be implemented as part of this capability?

## Deferred

- What may be needed later but is not part of the current capability definition?

## Boundary Notes

- Where does this capability start and stop?
- Which neighbouring capabilities does it interact with?
