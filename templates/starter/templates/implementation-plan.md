# Implementation Plan Template

## Objective

Complete the delivery slice exactly as scoped.

## Work Sequence

1. Read the implementation bundle fully.
2. Confirm the readiness gate.
3. Review allowed files and forbidden files.
4. Complete tasks in order.
5. Run the smallest relevant checks.
6. Update implementation notes.
7. Stop for review.

## Task Execution Rules

- Complete tasks in the order listed unless blocked.
- Do not expand scope.
- Do not modify files outside the allowed list.
- Do not implement deferred work.
- Do not reinterpret the capability from newer docs.
- Stop if acceptance criteria cannot be met.

## Required Implementation Notes

At the end of the work, report:

- Files changed
- Tasks completed
- Acceptance criteria met
- Checks run
- Risks remaining
- Follow-up work intentionally not done
