# 01 Purpose

Define why the project exists.

This section should explain the problem, the desired outcome, and the value the project must create.

## Guidance

Include:

- problem being solved
- desired outcome
- business or user value
- project goals
- definition of success

## Template

```md
## Problem

Describe the problem in clear terms.

## Desired outcome

Describe the outcome the project must produce.

## Value

Describe the business or user value.

## Goals

List clear goals.

## Non-goals

List things this project is not trying to achieve.
```
