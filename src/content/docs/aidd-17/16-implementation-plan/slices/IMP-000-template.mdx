## Stop Conditions

- Stop if required information is missing, contradictory, or ambiguous.
- Stop if files outside the expected scope are required.
- Stop if security, privacy, authentication, authorization, payments, regulated data, or audit logging are affected without explicit rules.
- Stop if acceptance criteria cannot be verified.
