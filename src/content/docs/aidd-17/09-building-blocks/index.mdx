# 09 Building Blocks

Define the major components, services, modules, packages, or subsystems.

Each building block should have one clear responsibility.

## Template

```md
# Building Block: [Name]

## Responsibility

What this block owns.

## Inputs

What this block receives.

## Outputs

What this block produces.

## Dependencies

What this block depends on.

## Rules

Rules this block must follow.
```
