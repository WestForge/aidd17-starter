# 04 Features

Define features that support the behaviours.

Features should map to behaviours.

## Guidance

Use feature IDs such as `F-001`.

A feature is not complete until its linked behaviours can be verified.

## Template

```md
# F-000 Feature Name

## Purpose

Why this feature exists.

## Linked behaviours

- B-000

## Scope

What this feature includes.

## Out of scope

What this feature does not include.

## Success criteria

What must be true for the feature to be accepted.
```
