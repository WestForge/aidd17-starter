---
title: Review Checklist
description: Checklist for reviewing implementation slices.
---

Use this checklist when reviewing implementation slices.

- Linked behaviours satisfied.
- Linked features supported.
- Architecture followed.
- Scope respected.
- Out-of-scope items avoided.
- Applicable rules followed.
- Tests added or updated.
- Verification performed.
- Assumptions listed.
- Documentation updated where needed.
