# 02 Users

Define who uses the system.

Users may be people, roles, teams, external systems, or AI agents.

## Guidance

Include:

- user types
- responsibilities
- permissions
- goals
- pain points
- constraints

## Template

```md
## User type

Name of user type.

### Goal

What this user needs to achieve.

### Responsibilities

What this user is responsible for.

### Permissions

What this user can access or change.

### Notes

Additional context.
```
